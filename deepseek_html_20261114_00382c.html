Довідник-помічник

Означення. Рівняння — це рівність, яка містить невідомі числа (змінні).

Означення. Значення змінної, яке перетворює рівняння на правильну числову рівність, називається коренем рівняння або розв'язком рівняння.

  • число 3 є коренем рівняння x + 5 = 8;
  • число 4 — корінь рівняння 3m/2 − 2 = m;
  • число (−1) є коренем рівняння y² − 4y = 5.

Розв'язати рівняння — означає знайти всі його корені або довести, що їх немає.

Властивості рівнянь з однією змінною

  1. Чи порушиться рівність, якщо до обох її частин додати одне й те саме число?
  2. Що станеться з рівністю, якщо обидві частини збільшити або зменшити в одну й ту саму кількість разів?
  3. Чи залишиться правильною рівність, якщо обидві її частини помножити на від'ємне число?

Основні властивості рівнянь

Означення. Рівносильними називають рівняння, якщо вони мають одні й ті самі корені. Також рівносильними вважають рівняння, які не мають коренів.

  1. У будь-якій частині рівняння можна розкрити дужки, якщо вони є, та звести подібні доданки.
  2. Доданки можна переносити з однієї частини рівняння в іншу, змінивши їхні знаки на протилежні.
  3. Обидві частини рівняння можна помножити або поділити на одне й те саме число, відмінне від нуля.

Лінійні рівняння: означення та алгоритм

Означення. Рівняння виду ax = b, де a та b — деякі числа, називається лінійним.

Алгоритм розв'язування

  1. Якщо a ≠ 0, то x = b/a.
  2. Якщо a = 0 і b = 0, то будь-яке число є коренем.
  3. Якщо a = 0 і b ≠ 0, то рівняння коренів не має.

Лінійне рівняння з двома невідомими

Означення. Рівняння виду ax + by = c, де a, b, c — деякі числа, називають лінійним рівнянням із двома невідомими.

Приклади лінійних:

  • ax + by = c
  • 3x + 6y = 18
  • 0·x − 3y + 6 = 0

Інші рівняння:

  • xy = 5
  • x² + y² = 16
  • y³ = x³ + 2x

Розв'язати — знайти всі пари чисел (x; y), що перетворюють рівняння у правильну рівність.

Наявність розв'язків у рівняннях із двома невідомими

  1. Безліч розв'язків: 5x + 3y = 8 → (1; 1), (1,6; 0) тощо. Коло x² + y² = 9.
  2. Один розв'язок: x² + y⁴ = 0 → (0; 0).
  3. Немає розв'язків: x⁴ + y⁴ = −6.

Системи лінійних рівнянь із двома невідомими

Розв'язок системи — пара значень невідомих, яка перетворює кожне рівняння системи в правильну рівність.

2x + 4y = 6,

5x − 4y = 1

Пара (1; 1) — розв'язок.
